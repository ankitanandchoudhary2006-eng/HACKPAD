# HACKPAD

<img width="4080" height="3072" alt="1000116048" src="https://github.com/user-attachments/assets/ba803352-46e9-4c73-8233-d6eb737cc22d" />

SO I make a 3x3 HACKPAD for myself . It is based on RP2040 and I tried it to make it compact as possible. It has a rotor Encoder as well . The PCB was designed on kicad and the CAD was designed on Fusion. It has diodes to prevent ghosting and LEDs as well. 

### Features
- Rp2040 Based
- Per switch LED
- Per switch diode for ghosting protection
- 3X3 Switch matrix design

# Build Instruction 

First Solder the Diodes and the HotSwap then Solder the LEDS after that Solder the Xiao RP2040 Board and at the END solder the Rotor Encoder also before plugging it . Check if there is any mis-connection , shot or disconnection.
